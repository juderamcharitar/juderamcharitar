## Selected work

### [How Much Does Limit Order Book Microstructure Add Beyond Quote Geometry?](https://github.com/juderamcharitar/latency-compensating-mm)

Empirical market-microstructure research using **269,330 timestamped 10-level limit-order-book snapshots** across BTC/USD, ETH/USD, and SOL/USD. The project tests whether microstructure features add predictive information beyond quote geometry and includes corrected labeling, leakage checks, temporal and blocked evaluation, robustness tests, and reproducible experiments.

[Read the paper](https://github.com/juderamcharitar/latency-compensating-mm/blob/main/paper_v4/main.pdf) · [View the repository](https://github.com/juderamcharitar/latency-compensating-mm)
